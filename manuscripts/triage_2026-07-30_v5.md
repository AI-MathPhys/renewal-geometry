# Formalization triage — revised manuscripts (2026-07-30)

Scope: the new **arithmetic monograph** (`artithetic/arithmetic.txt`, *The
Universal Grand Tensor: Conditional Closure Monograph V003*, 107 records),
the **rewritten SM_emergence v5** (140 records), and the **extended flagship**
(86 records, new "master programme" layer).  All ledgers pass
`scripts/check_statement_coverage.py`.  Non-theorem environments
(definitions, assumptions, open problems, ledgers, warnings, audits) are
`statement_encoded`; every theorem/proposition/lemma/corollary is
`conditional_interface` unless already proved.

Tiers (calibrated against what we have proved so far in `NCG/`):

- **E (easy)** — hours each; finite matrices, `decide` enumeration,
  rational/real algebra, the toolkit already used ~200 times.
- **M (medium)** — one to a few days; small reusable library builds,
  multi-step but elementary linear algebra/analysis.
- **H (hard)** — substantial new machinery (spectral theory of integral
  operators, explicit formula, ΨDO, modular theory).
- **C (conditional-assembly)** — the statement is an implication from strong
  declared hypotheses; formalizing the *implication* is E/M bookkeeping, but
  the hypotheses carry the real content (they are separately tracked or
  intentionally open).
- **X (external/open)** — equivalent to or containing an open problem
  (GRH/RH, twin primes, Goldbach, YM gap, NS, BSD, Hodge, P vs NP); only the
  reduction, never the certificate, can be formalized.
